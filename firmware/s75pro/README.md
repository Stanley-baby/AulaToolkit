# S75 Pro 配套固件：F108

本固件针对已经核对并实测的 **AULA S75 Pro V1.03、0C45:800A 硬件版本**。F108 增加有线模式下无需 App 常驻的灯屏休眠，保留 F106 无线深睡、快速唤醒与分阶段策略，不修改原生灯效渐灭算法。它不是 AULA 官方固件，同名型号的其他硬件批次尚未验收。

## F108 的有线行为

- 按最后一次键盘操作开始计时，复用预设、自定义 1～120 分钟或分阶段策略的第一个时间，关闭主灯、机身侧灯和 LCD。
- Mac 整机睡眠触发原有 USB 休眠路径时关闭灯屏；主机后台恢复 USB 活动不单独点亮灯屏，实际按键恢复。
- 清理 USB 恢复后的残留软件标志，修正 F107 在恢复后约 10 秒再次关闭灯屏的路径。
- App 和辅助进程退出后继续工作，没有新增常驻服务。

**只关闭 Mac 显示器时，不会立即同步关灯。**此时仍按键盘空闲时间计时。通过触控板唤醒 Mac 后，键盘也可能继续保持关闭，直到实际按键。有线灯屏关闭不代表测得无线深睡或低功耗电流。

## 保留的无线休眠

| 策略 | 达到设定时间后 | 再次输入 |
| --- | --- | --- |
| 深睡 | 原始无线深睡路径 | 可能有原版唤醒／重连等待 |
| 快速唤醒 | 关闭灯屏，保留蓝牙／2.4G 通信和按键扫描 | F106 实测输入完整、无明显重连等待 |
| 分阶段 | 先关闭灯屏，到第二个累计时间后深睡 | 第一阶段快速，深睡后恢复原版等待 |

例如 3 分钟关灯屏／5 分钟深睡，两个时间都从最后一次操作计算。F108 保留 F106 无线补丁区域和原无线深睡函数；既有蓝牙与 2.4G 实测记录来自 F106。蓝牙不能直接设置这些选项，请先经 USB 或 2.4G 配置。

## 在 App 内升级与恢复

1. 保存 App 配置，退出其他键盘驱动。App 只能备份自身已保存内容，不能完整读回键盘所有设置或屏幕素材。
2. 使用数据线连接并切到**有线**，保持稳定供电；一次只连接一把匹配的 S75 Pro。
3. 打开键盘的 **“设备”页面 → 固件**，选择内置 F108，核对版本与文件指纹，再点击开始。
4. 等待准备、擦除、4096 包写入、两次设备校验和重新连接；期间保持线缆连接。
5. 根据 App 提示应用已保存配置，输入 `abc123`，检查主灯、侧灯和小屏幕。

升级重写程序区，配置或屏幕素材可能需要重新应用，备份 App 配置不等于备份整个键盘。USB 版本标记 F108 不等于完整固件读回，应结合文件 SHA-256 和设备校验结果核对。

恢复入口提供**上一版 F106**，保留无线三种休眠策略，但失去 F108 的有线空闲关灯与 USB 恢复修正。App 会暂停普通通信、保存失败阶段和恢复状态；独立命令行恢复工具仍可使用已核验的镜像。恢复取决于设备是否仍能进入升级模式，不能仅凭重新枚举判定恢复成功。

## 验证范围

- 同一把键盘真实刷入本页 F108：4096 个 64 字节包，两次设备校验 `D821`，正常协议与版本检查通过。此次 F108 实刷使用共享写入器的命令行入口；App 的选择、备份、恢复及写入流程另有模拟测试，未重复进行 F108 图形界面实刷。
- 有线空闲 1 分钟关灯屏、直接输入与恢复已实测；F108 经用户确认：Mac 睡眠 90 秒内灯屏保持关闭，手动唤醒后 20～30 秒没有再次突然全灭，`abc123`／`asd` 完整，无感知延迟、漏字或连发。
- 本地 MCU 套件通过 532 项有线、1049 项无线及 8 项新增 USB 恢复场景。外设和 USB 中断由模拟驱动；它们不代替实机计时、屏幕或射频观测。
- 本仓库的聚焦回归 [test_wired_wake.py](test_wired_wake.py) 重建 F107 基线并复现 10 秒再次全灭，再执行 F108 的 8 项恢复场景，包含 USB 端点暂忙时的待发报告保留。
- 尚未测量精确延迟、电流、整夜待机、所有硬件批次，以及 F108 全套无线物理回归；F108 的无线代码保留范围由构建检查验证。

## 复现构建与回归

```sh
# F108：以仓库内已核验 F106 为输入
python3 firmware/s75pro/build_wired.py

# 上一版 F106：以仓库内已核验 F105 为输入
python3 firmware/s75pro/build.py

# 实际 Cortex-M0 指令回归，无设备访问
uv run --with unicorn==2.1.4 python firmware/s75pro/test_wired_wake.py
```

构建需要 Python 3 和支持 `armv6m-none-eabi` 的 Clang。输出在 `firmware/s75pro/build/`，要求与发布镜像逐字节一致；编译结果不同会被拒绝，不会自动接受新镜像，也不会刷写设备。这是对厂商二进制应用补丁，**不是完整厂商固件源码构建**。

F108 新增源码：[wired-dark.c](wired-dark.c)、[usb-restore.c](usb-restore.c)。F106 源码：[connected-dark.c](connected-dark.c)、[custom-sleep.c](custom-sleep.c)。F108 保留 F107 的代码布局以复现已实测镜像，再将 `0x36A` 恢复调用指向修正版；F107 不作为可选固件发布。
