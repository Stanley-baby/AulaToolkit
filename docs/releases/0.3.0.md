# AULA Toolkit 0.3.0 — macOS 与 S75 Pro F106

本次是此分支的首次集中发布：包含此前多轮验收的 Mac 适配、键盘预览与动画改进，以及 S75 Pro 的 App 内固件升级和 F106 休眠策略。

## 下载

- **Apple Silicon Mac**：下载文件名包含 `mac-arm64` 的 DMG 或 ZIP。
- **Intel Mac**：下载文件名包含 `mac-x64` 的 DMG 或 ZIP。
- **键盘固件**：`S75Pro-F106.bin` 为本次配套版本；`S75Pro-F105.bin` 为上一版恢复选项。
- `SHA256SUMS.txt` 列出下载文件的校验值。

要求 macOS 14.2 或更新版本。Mac 包为临时自签名，未经过 Apple 公证，请按仓库安装说明手动允许打开。本次以 DMG／ZIP 手动安装为主，不承诺自签名 App 的自动更新安装。

## App 改动

- 原生 Mac 窗口按钮、可调整窗口、菜单栏和 Dock 行为，改善窗口缩放和界面响应。
- 修正主题、语言的启动准备，减少首次打开时错误显示英文或深色界面的情况。
- 加入黑透键盘外观与细灯条、侧灯预览；概览随主题切换外观，灯效页采用新外观。
- 保留并校准主灯效果与预览，避免 Mac 下的灯效模式猜测覆盖用户选择。
- 按键 GIF 动画增加方向与取色控制，优化重复解码和实时帧显示；加入有线单键呼吸及停止后的静态恢复。
- 加入自定义硬件休眠时间、深睡／快速唤醒选择，以及 F106 分阶段休眠配置。
- 加入有线固件升级面板、已核验镜像选择、配置备份、后台独占写入、进度、两次设备校验、重连检查和恢复状态。
- 重设计 README，补齐连接方式对比、固件说明、补丁源代码与复现脚本。

## F106 固件

在已测试的 S75 Pro 版本上提供：

1. 1～120 分钟自定义硬件休眠，App 退出后继续生效。
2. 蓝牙和 2.4G 的深睡／快速唤醒策略。
3. 两段式休眠，例如最后按键后 3 分钟关闭主灯、机身侧灯和 TFT，累计 5 分钟后进入原始深睡路径。

快速阶段的 `abc123` 完整输入、深睡阶段的等待差异和灯屏恢复已通过人工观察。实际电流、精确延迟和所有硬件批次尚未测量。固件升级仅支持匹配设备的有线连接；安装 App 不会自动刷写键盘。

F106 SHA-256：

```text
5f8425131cf96e8878dee95950380b7fa788004e91540fbcf30b49d9b2ef2931
```

固件包含第三方厂商二进制，补丁范围与硬件限制请阅读仓库 `firmware/s75pro/README.md`。不要仅根据 S75 Pro 型号名称判断兼容。

## 保留的已知问题

- `#ff4747` 单键渐灭尾段仍可能偏红；未解决这一问题的 A1／B1 实验均不随此次发布。
- 动态灯效有时会误触发亮度提示。App-only 修复仍为草稿，可暂时在通知设置中关闭屏幕提示。
- 机身侧灯尚未实现任意 RGB 直接选色；已验证的是流动、轮换、沿用硬件颜色的常亮与关闭。
- Mac 熄屏时主灯和侧灯可立即熄灭，TFT 完整熄灭仍受键盘休眠计时控制。
- 其他继承设备的 Mac 实机验证未全部完成；蓝牙不提供直接配置通道。

## English

This macOS-focused release includes native window behavior, improved startup and lighting previews, key-animation controls, USB per-key breathing, an in-app reviewed firmware updater, and S75 Pro F106 hardware sleep. F106 supports custom timeouts, Bluetooth/receiver quick or deep wake, and a two-stage dark-then-deep policy.

Use the matching `arm64` or `x64` Mac download. Builds are ad-hoc signed, not notarized; manual installation is the supported release path. Firmware flashing is optional and USB-only. Lighting-tail compensation experiments are excluded. See the repository guides for compatibility, exact checksums, recovery and current limitations.
